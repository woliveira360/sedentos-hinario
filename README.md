# HCC Online — Hinário para o Culto Cristão

App web para buscar e visualizar hinos do Hinário para o Culto Cristão.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- React Router

## Desenvolvimento local

```bash
npm install
npm run dev
```

App sobe em `http://localhost:8080`.

## Build

```bash
npm run build
npm run preview
```

## Deploy

Projeto configurado para Vercel (Vite SPA). Build: `npm run build`, output: `dist`.
